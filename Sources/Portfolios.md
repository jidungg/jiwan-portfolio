# 다른 포트폴리오 문서

`Cases/*.md` 작성 전에 참고할 수 있는, 이미 작성된 포트폴리오·기술 문서 목록이다.
여기 내용을 그대로 베끼지 않는다 — 톤·구성 참고와 사실 확인 용도로만 쓴다.

## 읽는 순서

**본문 내용이 필요하면 PPTX → 블로그 → Notion 순으로 본다. PDF는 마지막이다.**
PDF 3종은 전부 이미지 기반이라 텍스트 추출이 안 되고(`pypdf`로 뽑으면 전 페이지가
빈 문자열), 사용자가 캡처해 주지 않으면 읽을 수 없다.

## PPTX (본문 확인의 1차 출처)

텍스트가 그대로 추출된다. 슬라이드별 텍스트 덤프 스크립트:

```bash
py -c "
import zipfile, re, html, sys
z = zipfile.ZipFile(sys.argv[1])
ns = sorted([n for n in z.namelist() if re.match(r'ppt/slides/slide\d+\.xml$', n)],
            key=lambda n: int(re.search(r'slide(\d+)', n).group(1)))
for n in ns:
    xml = z.read(n).decode('utf-8','replace').replace('</a:p>','\n')
    print('=== ' + n + ' ===')
    for chunk in xml.split('\n'):
        line = html.unescape(''.join(re.findall(r'<a:t>(.*?)</a:t>', chunk, re.S))).strip()
        if line: print(line)
" <파일경로>
```

Windows 콘솔 인코딩 때문에 표준출력으로 바로 뽑으면 깨진다. **파일로 쓰거나
스크래치패드에 저장한 뒤 읽을 것.**

**1~19번만 실제 내용이고, 20~37번은 미리캔버스 템플릿 문구가 그대로 남아 있다.**

## Notion — 팀에 배포한 가이드 문서

**사용자가 만들어 팀원에게 실제로 배포한 사용 설명서다.** 사례의 근거이자,
"남이 쓸 것을 만들고 문서까지 냈다"는 협업 근거 그 자체다.

- **애니메이션 툴 가이드**
  https://silicon-humor-0e8.notion.site/183c1ed420d180919dd0e1f85a7b341e
  기능 목록 → 화면 → 사용 방법 순. `.model`/`.model2d` 입출력, **FModel로 원작
  2D 리소스를 추출해 들여오는 절차**, 애니메이션 재생·속도·전환, 애니메이션 이벤트
  추가·편집·저장, 논애님 스프라이트 모델 일괄 변환.
  **주의 사항이 번호로 붙어 있다** — 폴더 구조 제약, Progress는 0~1,
  FunctionName은 Receiver 바인딩 키와 같아야 함 등. 버전 표기("2.09 추가됨")도 있다.

- **애니메이션 이벤트 가이드**
  https://silicon-humor-0e8.notion.site/184c1ed420d180a4949df8dfb7f0e4e0
  팀원이 따라 할 수 있게 **4단계 + 예시 코드**로 쓰였다. `.animevt` 준비 →
  프로토타입 등록 → `IAnimEventReceiver` 상속 후 `Bind_AnimEventFunc`로 문자열
  키에 함수 바인딩 → `ANIMEVTGENERATOR_DESC`에 Receiver·SenderModel 넣고 Clone.
  `std::bind`가 처음인 팀원을 위한 설명까지 들어 있다.

기술소개서 슬라이드 72에 이 가이드를 팀과 공유했다는 언급이 있고, 포트폴리오
슬라이드 11에는 상호작용 시스템 가이드도 배포했다고 적혀 있다(링크 미확보).
Shipgend 이벤트 시스템 설명서까지 합치면 **세 프로젝트에 걸친 반복 습관이다.**
